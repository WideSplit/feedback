# WideSplit — issues and feature requests

WideSplit is a menu bar app for macOS that turns one wide monitor into
separate screens that macOS knows — each with its own Spaces and its own
full-screen apps. → [WideSplit.app](https://widesplit.app)

[![WideSplit in 30 seconds — watch on YouTube](https://img.youtube.com/vi/e5erJzkUtlg/maxresdefault.jpg)](https://youtu.be/e5erJzkUtlg)

▶ **[Watch WideSplit in 30 seconds](https://youtu.be/e5erJzkUtlg)**

**This repository has no source code.** It's where you report problems,
ask for features and follow what changes from build to build.

WideSplit is a free beta. Some things will break. When they do, we're sorry — and we'd like to hear
about it here.

## Report a problem

1. **Search first** — open and closed issues. If your problem is already
   here, add a 👍 or your details to it instead of opening a new one.
2. **Check your build** — the Updates section of the WideSplit menu shows
   it. New beta builds reach testers by email.
3. **Open a [bug report](../../issues/new?template=bug_report.yml).**

**Everything in this repository is public, including attachments.**
Please don't paste diagnostic reports or logs here — they can include
your macOS user name, identifiers of your monitors and the names of apps
and windows you had open. Email them to support@widesplit.app and mention
the issue number.

## Request a feature

Open a [feature request](../../issues/new?template=feature_request.yml).
Tell us what you're trying to do and what gets in the way — the problem
helps us more than a finished design. Add a 👍 to requests you'd like too.
We can't build every one, and we don't promise dates.

## Private matters

Licences, anything personal, or if you'd rather not use GitHub:
**support@widesplit.app**. How we handle your email:
[WideSplit.app/privacy](https://widesplit.app/privacy/).

## Security

Please don't open a public issue. Email support@widesplit.app.

## Known issues and what's new

- **Known issues** in the current build: issues labelled
  [`known-issue`](../../issues?q=is%3Aissue+label%3Aknown-issue), pinned at the top.
- **What changed** in each build: [Releases](../../releases) (from the next build on).

## Turning the split off

Choose **Stop the magic** in the WideSplit menu or press **⌃⌥⌘S**.
Screen stuck? **⌃⌥⌘P** returns your monitor to full screen at any time.

## Response times

We read everything. WideSplit is made by a small team, so replies can take
a few days, and there's no guaranteed response time during the beta.
An issue's labels and status show where it stands.

You can write in English or in Polish. Please keep it civil — we'll close
threads that aren't.
